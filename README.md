# gztes.github.io

My personal site: https://gztes.github.io

Built on [devportfolio](https://github.com/RyanFitzgerald/devportfolio) by Ryan Fitzgerald (Astro + Tailwind, MIT). All content lives in `src/config.ts`.

```bash
npm install
npm run dev
```

Deploy: `npm run deploy` (builds and force-pushes `dist/` to the `gh-pages` branch).
